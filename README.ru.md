# OpenBrush для Codex

[OpenBrush для OpenCode — установка](OPENCODE.md)

OpenBrush — русскоязычный форк [ZSeven-W/codex-openpencil](https://github.com/ZSeven-W/codex-openpencil) на базе редактора OpenPencil. Редактор и файлы работают локально. Отдельная подписка на редактор и ключ API для использования через текущий Codex не нужны. Работа модели Codex требует её обычного подключения и расходует лимиты вашего аккаунта.

Русифицированы оболочка холста, сохранение, выделение и панель генерации кода. Плагин передаёт `ru` при первой загрузке и повторной инициализации. Нужен соответствующий [форк Rust-движка](https://github.com/ex3lite/openpencil/tree/codex/russian-localization): в исходной стабильной сборке протокол встраивания разрешает только `zh-CN` и `en-US`.

В локальной версии 0.8 редактор называется OpenBrush и автоматически привязывается
к папке текущего чата Codex. Макеты сохраняются прямо в ней, без вложенной папки
`designs`. Панель и агент используют один сеанс холста, даже когда Codex запускает
для них разные процессы. При открытии отдельной панели она один раз отправляет
в текущий чат запрос на подключение; выбирать папку вручную не нужно.

Сохранены список макетов проекта, адресные комментарии, просмотр передаваемого
контекста и совместная работа до десяти субагентов с оригинальными курсорами
редактора. Кнопка разворота использует режим панели Codex.
[Рабочий процесс и ограничения](docs/workspace.md).

Изменения автоматически записываются в `.op`. Кнопка «История» показывает
локальные версии и восстанавливает выбранную с сохранением текущего состояния.
История ограничена 50 снимками / 128 МиБ на документ. Ошибка или внешняя правка
файла останавливает запись и показывается в интерфейсе.

«Библиотека» ищет в общей локальной библиотеке и напрямую в Figma
Community через MCP. Поиск не отправляет отдельный запрос модели. Ресурсы сохраняются с автором, лицензией, источником и
контрольной суммой. SVG импортируется в редактируемые векторы, изображения — в
слой изображения, `.op` — как макет проекта. `.fig` сохраняется как исходник и передаётся штатному импортёру Figma редактора.
Совместимость сложных файлов зависит от возможностей исходного импортёра.

## Сборка локального runtime

1. Соберите WebAssembly по `README.ru.md` в форке движка.
2. Подготовьте штатный runtime 0.8.5/d155cd0: `npm run setup`. Существующая установка подходит.
3. Соберите отдельный runtime, указав абсолютные пути:

```sh
node scripts/localize-runtime.mjs /absolute/base-runtime /absolute/openpencil /absolute/new-russian-runtime
npm run configure-runtime -- /absolute/new-russian-runtime
```

Скрипт проверяет исходный runtime, сохраняет его daemon и CanvasKit, заменяет WASM/JS и каталоги из чистого Git-коммита форка. Новый манифест содержит SHA коммита локализации и SHA-256 каждого файла. Исходная установка сохраняется; существующий каталог назначения не перезаписывается.

Подключите локальный marketplace из этого репозитория в Codex. Для ручного запуска: `npm run canvas -- --project-root /absolute/project --file /absolute/document.op`. Параметр `--project-root` обязателен; без `--file` создаётся новый черновик в выбранном проекте. Файл `.op` сохраняет редактируемые слои.

## Проверка

```sh
npm run check
npm test
npm run smoke -- --binary /absolute/new-russian-runtime/bin/op-host-web-server
```

Smoke-тест создаёт отдельный тестовый документ. Не используйте пользовательский макет как тестовый файл. Лицензия исходного проекта — MIT; авторство и лицензии вложенных компонентов сохранены.

## Библиотека и контекст в 0.8

Библиотека показывает оригинальные обложки Community с сохранённым URL и SHA-256,
включая AVIF. При недоступной обложке показывает отсутствие исходника. В настройках
библиотеки можно отключить проверку лицензии; неизвестные условия явно остаются
на ответственности пользователя. Поиск через Codex не ограничен типом ресурса;
публичные HTTPS-загрузки поддерживают сайты авторов, CDN и репозитории.

Выделение само не отправляется агенту. «Контекст» → «Добавить в контекст» закрепляет
слои как явные вложения. Там видны точные данные и кнопки удаления. Смена выделения,
автосохранение и история не дописывают новые данные в контекст.

## Большие наборы и общая библиотека в 0.9

Документы передаются между панелью и движком сжатыми частями с проверкой SHA-256.
Переключение страницы передаёт только состояние просмотра. Исходные страницы, слои
и изображения не отрезаются. Ограничение документа отделено от небольшого лимита
сообщения MCP; история рассчитана на большие версии.
Рабочий бюджет документа — 256 МиБ несжатого JSON; библиотека сохраняет оригиналы
дизайнов до 1 ГиБ. Превышение возвращает ошибку и сохраняет оригинал целиком.
В режиме Codex точечная правка не запускает автоматическую переделку чужих слоёв.

Общая библиотека находится в локальном каталоге состояния OpenBrush. Проекты
содержат ссылки на скачанные оригиналы, а редактируемые макеты создаются как
отдельные копии проекта. При первом обращении старые ресурсы проекта переносятся
в общую библиотеку с проверкой контрольных сумм. Конвертер Figma входит в полный
локальный runtime и автоматически индексирует все страницы и названия компонентов.
Автоподбор включён: агент может сам искать, скачивать, разбирать и использовать
ресурсы для текущей задачи. Его можно отключить в настройках библиотеки.
Полный индекс остаётся локальным: агент получает сводку страниц и ограниченную
выборку найденных названий, а не всё содержимое UI Kit в контекст.

Для сборки полного runtime из чистого коммита форка (собранные web/WASM,
`target/release/op-host-web-server` и `target/release/op`):

```sh
node scripts/stage-fork-runtime.mjs /absolute/base-runtime /absolute/engine /absolute/new-runtime
node scripts/build-native-editor.mjs /absolute/new-runtime
npm run configure-runtime -- /absolute/new-runtime
```

## Автоматические шрифты в 0.10

OpenBrush определяет семейства, начертания и нужные символы на всех страницах,
включая rich text, переменные и переопределения компонентов. Открытые гарнитуры
скачиваются по необходимости из официального Google Fonts и сохраняются один
раз в общей библиотеке. Версия источника, исходные байты и лицензия фиксируются
контрольными суммами. Файлы шрифтов не встраиваются в проект или плагин.

Три инструмента доступны агенту:

- `canvas_fonts_status` — требования макета и реальное состояние native/CanvasKit.
- `canvas_fonts_prepare` — определить и подключить шрифты текущего макета либо
  загрузить выбранные агентом семейства через `families`, `weights`, `styles`.
  `cyrillic: true` проверяет весь русский алфавит. Инструмент не меняет слои.
- `canvas_fonts_library` — посмотреть общий кэш гарнитур с источниками и лицензиями.

Открытие, переключение макета, импорт UI Kit, новые текстовые слои и изменения
шрифта запускают этот же механизм автоматически. Повторные обращения используют
кэш; начертания выбираются по реальным данным файлов. Недоступные семейства,
символы и неточные веса сообщаются явно. Noto Sans служит резервом для кириллицы
без переименования исходного шрифта в слоях. Автономия и проверка лицензий следуют
общим настройкам библиотеки. В панели библиотеки есть раздел «Шрифты».

## Пакеты и референсы

Coolicons включён в каталог базового пресета. Полный пакет скачивается один раз
в общую библиотеку, а в проект добавляются выбранные редактируемые SVG. Каталог
хранит исходный Figma Community ID `800815864899415771`, автора, версию релиза,
оригинальный ZIP, лицензию и SHA-256 каждого объекта. В интерфейсе пакет занимает
одну карточку с поиском по названию, стилю и форме углов.

Инструменты агента: `canvas_icon_pack_list`, `canvas_icon_pack_acquire`,
`canvas_icon_pack_search`, `canvas_icon_pack_select`, `canvas_icon_pack_check`,
`canvas_icon_pack_update`. Для новых найденных пакетов поддерживается общий
manifest публичного GitHub SVG-релиза. Обновления сохраняют старые версии и не
перезаписывают слои проектов. Обычные Community-ресурсы также сохраняют исходный
числовой Community ID; Figma file key записывается отдельно.

Поиск референсов выполняет сам агент через прямые инструменты каталога Community. Например, задача со стилем Apple запускает поиск и выбор
подходящих примеров, затем их сохранение в общую библиотеку и использование в
макете. Исходный URL, автор и условия сохраняются; содержимое ссылок не считается
инструкциями для агента.

## Прямой Figma Community MCP в 0.11

Каталог читает публичные карточки в подключённом Chrome через детерминированный
reader существующего расширения Kakadu Browser Agent. Поиск не вызывает модель,
Perplexity или поисковую систему. Требуется запущенный Chrome с обновлённым reader;
при недоступности возвращается конкретная ошибка, скрытой подмены поиска нет.
Приватные API, извлечение cookies и токенов не используются.

Инструменты: `canvas_community_catalog_status`, `canvas_community_catalog_search`,
`canvas_community_catalog_get`, `canvas_community_catalog_acquire`,
`canvas_community_catalog_check`. Они сохраняют исходный Community ID, автора,
оригинальную обложку, наблюдаемую лицензию и версии метаданных. Обложка сохраняется
как растровый референс; редактируемый импорт требует реальной публичной ссылки
на `.fig`, `.op` или `.svg`. «Open in Figma» само по себе не является такой ссылкой.
Обновление карточки не заменяет ранее скачанные ресурсы и слои проекта.

Настройка приватного bridge:

```sh
node scripts/configure-community-browser.mjs EXTENSION_ID /absolute/private/bridge
```

Для другого MCP-клиента доступен тот же сервер отдельно: команда `node`, аргументы
`/absolute/checkout/plugins/openpencil/scripts/figma-community-mcp.mjs`,
`--project-root`, `/absolute/project`. Его команды называются
`figma_community_status/search/get/acquire/check`. В Codex отдельный дублирующий
сервер не нужен: инструменты входят в OpenBrush и используют проект текущего чата.

## Центрирование и открытые сеансы в 0.11.1

Движок центрирует подписи по реальной ширине текстового слоя: запас для
переноса строки больше не смещает текст и каретку вправо. Для кнопок используется
симметричный padding и естественная высота строки; подпись центрируется контейнером.
Активный браузерный холст удерживает свои UI-ресурсы в памяти, поэтому удаление
старого кэша при обновлении плагина не ломает последующее открытие этого холста.
