# OpenBrush для Codex

OpenBrush — русскоязычный форк [ZSeven-W/codex-openpencil](https://github.com/ZSeven-W/codex-openpencil) на базе редактора OpenPencil. Редактор и файлы работают локально. Отдельная подписка на редактор и ключ API для использования через текущий Codex не нужны. Работа модели Codex требует её обычного подключения и расходует лимиты вашего аккаунта.

Русифицированы оболочка холста, сохранение, выделение и панель генерации кода. Плагин передаёт `ru` при первой загрузке и повторной инициализации. Нужен соответствующий [форк Rust-движка](https://github.com/ex3lite/openpencil/tree/codex/russian-localization): в исходной стабильной сборке протокол встраивания разрешает только `zh-CN` и `en-US`.

В локальной версии 0.7 редактор называется OpenBrush и автоматически привязывается
к папке текущего чата Codex. Макеты сохраняются прямо в ней, без вложенной папки
`designs`. Панель и агент используют один сеанс холста, даже когда Codex запускает
для них разные процессы. При открытии отдельной панели она один раз отправляет
в текущий чат запрос на подключение; выбирать папку вручную не нужно.

Сохранены список макетов проекта, адресные комментарии, просмотр передаваемого
контекста и совместная работа до десяти субагентов с оригинальными курсорами
редактора. Кнопка разворота использует режим панели Codex.
[Рабочий процесс и ограничения](docs/workspace.md).

Изменения автоматически записываются в `.op`. Кнопка «История» показывает
локальные версии и восстанавливает выбранную с сохранением текущего состояния.
История ограничена 50 снимками / 128 МиБ на документ. Ошибка или внешняя правка
файла останавливает запись и показывается в интерфейсе.

«Библиотека» ищет в локальном датасете проекта и передаёт запросы на поиск в Figma
Community агенту Codex. Ресурсы сохраняются с автором, лицензией, источником и
контрольной суммой. SVG импортируется в редактируемые векторы, изображения — в
слой изображения, `.op` — как макет проекта. `.fig` сохраняется как исходник и передаётся штатному импортёру Figma редактора.
Совместимость сложных файлов зависит от возможностей исходного импортёра.

## Сборка локального runtime

1. Соберите WebAssembly по `README.ru.md` в форке движка.
2. Подготовьте штатный runtime 0.8.5/d155cd0: `npm run setup`. Существующая установка подходит.
3. Соберите отдельный runtime, указав абсолютные пути:

```sh
node scripts/localize-runtime.mjs /absolute/base-runtime /absolute/openpencil /absolute/new-russian-runtime
npm run configure-runtime -- /absolute/new-russian-runtime
```

Скрипт проверяет исходный runtime, сохраняет его daemon и CanvasKit, заменяет WASM/JS и каталоги из чистого Git-коммита форка. Новый манифест содержит SHA коммита локализации и SHA-256 каждого файла. Исходная установка сохраняется; существующий каталог назначения не перезаписывается.

Подключите локальный marketplace из этого репозитория в Codex. Для ручного запуска: `npm run canvas -- --project-root /absolute/project --file /absolute/document.op`. Параметр `--project-root` обязателен; без `--file` создаётся новый черновик в выбранном проекте. Файл `.op` сохраняет редактируемые слои.

## Проверка

```sh
npm run check
npm test
npm run smoke -- --binary /absolute/new-russian-runtime/bin/op-host-web-server
```

Smoke-тест создаёт отдельный тестовый документ. Не используйте пользовательский макет как тестовый файл. Лицензия исходного проекта — MIT; авторство и лицензии вложенных компонентов сохранены.
